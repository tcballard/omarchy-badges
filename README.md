# Omarchy Badges

A little label for things built with Omarchy in mind.

[![Built for Omarchy](https://raw.githubusercontent.com/tcballard/omarchy-badges/85f859029e236e784e7b05ada6dbe73506d07a91/badges/v1/built-for-omarchy.svg)](https://github.com/tcballard/omarchy-badges)

## Add it to your README

Copy this line below your project title:

```markdown
[![Built for Omarchy](https://raw.githubusercontent.com/tcballard/omarchy-badges/85f859029e236e784e7b05ada6dbe73506d07a91/badges/v1/built-for-omarchy.svg)](https://github.com/tcballard/omarchy-badges)
```

That's it. No account, registration or approval required. Plugins, native apps, games and developer tools are welcome.

## What it means

“Built for Omarchy” is a community author's statement that the project was built with Omarchy in mind. It is not an official endorsement, security review, marketplace acceptance or guarantee of compatibility. Keep supported versions and testing details in your own README.

## A stable image

The snippet pins the SVG to an exact Git commit. Its artwork will stay the same when this repository changes. Future designs will get separate paths and snippets; adopting them is your choice.

The first design is also available at [badges/v1/built-for-omarchy.svg](badges/v1/built-for-omarchy.svg). Download it into your own repository if you prefer a local image.

- 164 × 24 pixels; approximately 4.3 KB.
- Official Omarchy icon, charcoal background and warm ivory lettering.
- JetBrains Mono Medium lettering stored as vector shapes.
- No external fonts, scripts or image dependencies.
- Accessible title and image label.

For a local copy, put the file at `assets/built-for-omarchy.svg` and use:

```markdown
[![Built for Omarchy](assets/built-for-omarchy.svg)](https://github.com/tcballard/omarchy-badges)
```

## Help it spread

Add it to something you're building, or share this repository with another Omarchy maintainer. Issues and PRs are welcome for rendering problems and useful improvements. Please keep the badge compact and existing designs stable.
